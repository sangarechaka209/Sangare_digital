# SANGARE DIGITAL SOLUTIONS

Site vitrine statique en HTML et CSS. Aucun outil de compilation ni dépendance serveur n'est nécessaire.

## Publier avec GitHub Pages

1. Créez un dépôt GitHub et ajoutez-y `index.html` et ce fichier `README.md`.
2. Envoyez les fichiers sur la branche `main`.
3. Dans le dépôt, ouvrez **Settings > Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche **main** et le dossier **/(root)**, puis cliquez sur **Save**.
6. Après le déploiement, GitHub affichera l'adresse publique dans cette même page.

Pour un dépôt nommé `nom-utilisateur.github.io`, l'adresse sera `https://nom-utilisateur.github.io/`. Pour un autre nom de dépôt, elle sera `https://nom-utilisateur.github.io/nom-du-depot/`.

## Avant la publication

- Vérifiez le numéro de téléphone et l'adresse affichés dans `index.html`.
- La photo et les polices sont chargées depuis des services externes et nécessitent une connexion Internet.
